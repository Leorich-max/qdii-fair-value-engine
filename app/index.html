Nasdaq-100 QDII ETF premiums

Twelve China-listed ETFs that hold the Nasdaq-100. Each day's fair value is rebuilt from the fund's last published NAV, QQQ's move since that NAV's valuation date and the CFETS USD/CNY parity, and compared with the closing price.

A small residual means the valuation-date and currency conventions explain the published NAVs; it is not a measure of trading profit.

Calculator

FV = NAV(D) × QQQ latest / QQQ on D × FX now / CFETS parity on D. Same formula as reconstruct_fair_value in the Python package (tested against it). The charts use QQQ total return (dividends added back); this calculator uses plain closes.

What this page does and does not show

  • Prices are A-share closing prices. QQQ is its last US close before that day, so moves in overnight QQQ trading and Nasdaq futures during Asian hours are not included; on a big overnight day part of the "premium" is that move.
  • FX uses the CFETS central parity of the day, the same basis funds use for NAV; market USD/CNH can differ by tens of basis points.
  • The NAV used is the latest valuation date before each day. The source gives no publication time, so for history this is a convention; from the first daily run onward the page records when each NAV was first seen.
  • Days with a missing input are left as gaps. Nothing here is investment advice or a trading signal.
